# COGENT — Enterprise AI Automation Agency

A luxury, high-ticket AI Automation Agency landing page built to convert enterprise clients.

## Tech Stack

- **Next.js 14** (App Router, TypeScript)
- **Tailwind CSS** — modern dark-mode design system
- **GSAP + ScrollTrigger** — buttery-smooth scroll animations, parallax hero, staggered section reveals
- **next/font** — Fraunces (display), Manrope (body), JetBrains Mono (data/labels)

## Getting Started

```bash
# install dependencies
npm install

# run the dev server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build for production

```bash
npm run build
npm run start
```

## Design System

- `--bg` `#0A0B0E` — graphite black canvas
- `--bg-elev` `#111319` — elevated panel
- `--ink` `#F5F3EE` — warm off-white text
- `--ink-dim` `#9A9CA6` — secondary text
- `--brass` `#C9A227` — luxury accent (authority, high-ticket)
- `--brass-glow` `#E8C766`
- `--signal` `#4F7CFF` — electric "automation" accent
- `--signal-glow` `#86A8FF`
